一只趴在雨里的小海豹。纯手写的 Canvas 单页场景，**零依赖、零构建、零网络请求** —— 双击 `index.html` 就能跑。

## 形体是怎么做出来的

主躯干是一圈圈「放样环」堆出来的软体，尾鳍和两只前鳍是独立的椭球小块。

渲染走的是**三渲二**：按面片法线做兰伯特着色，但不画任何接缝 —— 每个面片的可见面并成一条路径、用一次性水彩渐变填掉，只在真正的侧影棱上用带抖动的钢笔线重描一遍。所以整只海豹读起来是一笔连下来的，而不是一堆多边形的拼贴。
